# TV Glowup debloat list: OnePlus Y Series, Android 11 (MediaTek, build "shibuya"), 1 GB RAM.
#
# install.sh runs `pm disable-user --user 0 <package>` for every line below.
# Nothing is uninstalled. Every line is reversible at any time:
#     adb -s $TV shell pm enable <package>
# or run ./restore.sh to put back everything at once.
#
# Lines starting with # are ignored. Package names only, one per line.
